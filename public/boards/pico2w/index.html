Cautions for this board

  • RP2350-E9 (A2 stepping): a Bank 0 GPIO configured as an input can be held at about 2.2 V by pad leakage while its voltage is in the undefined logic region; the internal pull-down is too weak to overcome it. Pull or drive the line low with 8.2 kΩ or less; the pull-up still works. Source: [1]

Model-specific features and connection notes

  • Two cores run concurrently; all four cores cannot run together. 12 PIO state machines. [a]
  • Board exposes 26 GPIOs and 3 external ADC inputs. GP29 is used for on-board measurements. [c]
  • CYW43439: 2.4 GHz Wi-Fi and Bluetooth 5.2. Wireless silicon does not increase MCU RAM. [b]
