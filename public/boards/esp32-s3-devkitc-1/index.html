ESP32-S3-DevKitC-1 v1.1 pinout

ESP32-S3-WROOM-1-N8 · 3.3 V I/O

Open in the interactive atlas →See the pin map, choose functions and save a wiring plan.Türkçe

USB at bottom; J1 left, J3 right. DevKitC-1 v1.1 with WROOM-1-N8 Quad flash. The RGB LED uses GPIO38; v1.0 differs. GPIO0/3/45/46 are strapping pins and GPIO19/20 share USB. S3 GPIO46 supports both input and output. Select the N8R8 reference for Octal PSRAM restrictions.

General usage notes

3.3 V I/O; do not apply 5 V. Matrix choices need SDK pin routing and peripheral configuration. I²C requires open-drain operation and suitable pull-ups.

Model-specific features and connection notes

  • GPIO matrix rows describe routing capability, not firmware defaults. Maintain correct strapping levels during reset. [a] [b]
  • v1.1 RGB LED: GPIO38; initial revision uses GPIO48. On N8R8, GPIO35/36/37 are reserved for Octal PSRAM. [b]
